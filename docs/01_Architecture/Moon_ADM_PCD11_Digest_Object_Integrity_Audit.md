# Moon ADM PCD-11 — Selected Input Digest Object Integrity Audit

Date: 2026-10-15
Status: local integrity hardening implemented; PCD-11 digest semantics remain open

## Finding

`ADMMonthlyDataAssessment.__post_init__()` previously checked only that `selected_input_digest` was a 64-character lowercase hexadecimal string. The digest was correctly generated by `assess_adm_monthly_dataset()`, but the dataclass did not verify that a supplied digest matched the selected observations represented by the assessment's relative- and absolute-momentum inputs.

As a result, direct construction or `dataclasses.replace()` could retain or inject a syntactically valid but unrelated digest while the assessment's selected observations differed. This was an object-integrity gap, not a signal-activation path: the assessment remains an audit/readiness object and does not create `ADMSignalInput`.

## Change

- Extracted the existing canonical selected-observation digest calculation into `_selected_adm_input_digest()`.
- The assessment constructor now recomputes the digest from its selected observation pairs and rejects a mismatch.
- `assess_adm_monthly_dataset()` uses the same helper, so generation and validation share one canonicalization implementation.
- Added a regression test that replaces the digest with another valid SHA-256-shaped value and expects `ValueError`.
- Existing mapping insertion-order regression remains in place.

## Scope and non-goals

- The digest payload and canonical JSON settings are unchanged: sorted JSON keys, compact separators, UTF-8, `ensure_ascii=False`, and `allow_nan=False`.
- Observation metadata, including `retrieved_at` where present, continues to affect the digest. Whether that is the intended PCD-11 semantic contract remains unresolved.
- No provider, live API, investment calculation, governance approval, signal assembly, or strategy activation behavior was changed.
- `config/moon.yaml` must continue to use `active_strategies: []`.

## Validation

- Full suite on Python 3.13.5: `436 passed in 4.24s`.
- No live Alpha Vantage calls were made.
- The project-designated Python 3.12.13 environment still needs verification on the user's local machine after selective merge.

## Remaining limitations

This check binds the digest to the selected observations present in the assessment object. It is not a digital signature, an external authority check, a durable audit log, or proof that the source data itself is authentic. Those governance and provenance questions remain separate.
